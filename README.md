# 🚀 Desafio de Layout com CSS Flexbox

Este projeto foi desenvolvido para exercitar o uso avançado do **CSS Flexbox**, manipulando direções de eixos, largura de elementos e alinhamentos individuais.

## 📌 Funcionalidades implementadas

- **Exibição em Linha (`flex-direction: row`):** O conteúdo interno do `<article>` (imagem e texto) é exibido lado a lado.
- **Cards em Largura Total (`flex: 1 1 100%`):** Cada card ocupa 100% da largura da tela, criando uma lista de postagens horizontais largas.
- **Alinhamento Customizado (`align-self`):** A imagem do card utiliza `align-self: flex-start` para alinhar-se ao topo, quebrando o alinhamento centralizado padrão do elemento pai.

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Flexbox)
- **JavaScript** (Manipulação básica do DOM)
